# Dayflow — Daily Planner

A responsive daily productivity planner built with HTML, CSS and vanilla JavaScript.

## Features
- Dashboard with task statistics and weekly activity
- Task creation, editing, deletion, due dates, time and priority
- Daily schedule
- Monthly calendar with tasks by date
- Goals with progress tracking
- Weekly habit tracker
- Notes
- Light/dark theme
- JSON backup export and import
- Local browser storage

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a **Public** GitHub repository named `daily-planner`.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your app URL will look like:
   `https://YOUR-USERNAME.github.io/daily-planner/`

## Important data note
This first version saves data in the browser's Local Storage. Data stays on the same browser and device. It does not automatically sync between devices or browsers. Use Settings → Export backup to save a JSON copy, and Import backup to restore it.
